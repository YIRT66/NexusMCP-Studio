# NexusMCP 网页聊天助手 1.3.1

在 Edge / Chrome 的扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，选择本目录。适用于 NexusMCP Studio 0.3.1。随后在客户端的「AI 浏览器」面板中选择「Edge / Chrome 扩展」，复制本机连接地址到本扩展弹窗，点击连接。

在客户端点击打开对应网页，完成正常登录后，即可从软件聊天栏发消息、接收网页回复。连续消息始终复用当前客户端会话绑定的网页标签；客户端新建会话才分配新标签。

扩展只与客户端提供的 `ws://127.0.0.1:<端口>/webchat/extension/<本机配对值>` 连接。不要把 GPT 的公网 MCP 地址粘贴在这里。聊天适配器不读取密码或 Cookie，不绕过网站登录或验证码。手动开启的网页调试功能会执行用户指定的脚本，使用页面本身的权限。

网站发生页面改版时可能需要更新 `adapter.js` 的选择器。附件与网站内部模型选择在网页完成。

## 界面与操作

- 顶部状态显示实际 WebSocket 连接结果；连接中与未连接会分别提示。
- 「连接设置」中粘贴客户端提供的完整地址。连接成功后可折叠设置，断开连接会清除自动重连地址并保留网页会话；任务进行中需要先在客户端停止。
- 「当前会话」可一键打开已绑定的网页。连续消息复用同一个客户端会话的对话。
- 展开「直接操作当前网页」可发送、停止和复制最新回复。Ctrl / ⌘ + Enter 发送；发送失败保留草稿，错误提示可关闭。
- 跟随系统深浅主题，提供键盘焦点、读屏状态提示及减少动态效果支持。

Windows / Linux 的 Chrome、Chromium、Edge 使用同一份扩展。更新后在扩展管理页点击重新加载，并刷新已打开的 AI 网页。

开发验证：在项目根目录运行 `node scripts/test-extension-popup.mjs`。测试会检查两种主题与主要操作，并输出 `output/extension-ui/` 截图。

## 完成检测与网页调试

### 无原生 MCP 的网页模型（1.3）

DeepSeek 等模型通过浏览器扩展收发 `nexus-tool-v1` JSON 代码块，由客户端校验当前 requestId/sessionId、工具名称和参数，再执行本机工具。无需给网站安装 MCP。工具结果自动送回同一网页回合，最终正文显示在软件内。逐次审批、只读权限及禁用工具设置同样生效。重复调用 id 不重复执行，最多 24 轮；停止后迟到的工具请求不执行。ChatGPT 继续优先使用原生 MCP。

网页上的按钮、表单与模型输出会随网站更新改变；扩展不会自动重试一次发送结果不明的提交。断线或任务超时请先检查状态再继续。

声明式组件使用 `nexus-ui` 代码块，支持 `card`、`table`、`metrics`、`chart`；详见版本说明。扩展从 DOM 保留表格和代码块，客户端不会执行模型回复里的任意 HTML/JS。

1.2 支持 iframe 聊天框发现、接收器失效后重新注入、扩展重启恢复绑定，以及按 requestId 确认本轮网页回复已稳定完成。优先接收 MCP 回传，没有回传时同步网页最终正文；不会用旧回复完成新请求。标签绑定失效时可点击「绑定当前 AI 标签页」。

控制台及 JS/CSS 注入需点击「开启网页调试」启用当前网页调试（扩展安装时声明 debugger 权限），只调试当前绑定网页。浏览器会显示提示条，可以点击「关闭网页调试」断开。之后 MCP 的 `browser_console_read`、`browser_console_control` 和 `browser_inject` 可使用 `target=chat` 操作。
