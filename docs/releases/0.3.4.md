# NexusMCP Studio 0.3.4

网页和桌面使用同一个服务时，会话、草稿、项目、当前会话选择和 MCP 消息实时互通。服务端保存后广播更新，客户端仅提交改动字段，旧浏览器缓存不再覆盖新草稿。

`client_reply` 无需等待软件发起问题：没有待回复任务时，可指定 `sessionId` 主动推送通知、进度或结果；分段续传使用返回的 `requestId`。主动通知不会生成虚假的用户消息，也不会结束其他任务。

增加持久化运行日志、脱敏和大小轮换，可在标题栏「运行日志」查看、复制或导出。服务、MCP、原生插件或界面异常时暂停任务，展示时间、来源、堆栈和日志目录；服务守护检测进程退出和心跳超时，只恢复处于暂停状态的控制界面。用户手动解除暂停后重新加载界面，不自动重放命令。桌面主进程异常也保存错误，日志保留上一轮启动记录。

按本次要求采用必要检查：同步/主动 MCP 消息、故障持久化、真实进程崩溃恢复，以及一次双端界面联调和构建检查；本补丁的快速发布不运行完整的历史界面回归。
