# NexusMCP Studio 0.3.0

- **文件效率**：`file_read` 支持按行/字节限额读取；`file_read_many` 最多四路并发；`file_patch_many` 在同一文件内顺序校验全部修改后一次写入。文件写入串行化，支持 SHA-256 冲突检查，普通文件使用临时文件替换，保留基本权限和符号链接目标。硬链接使用原 inode 写入，保留链接关系。
- **终端**：PTY 输出按 cursor/limit 分页；无新输出时等待，新输出/退出立即唤醒。`terminal_signal` 支持 Ctrl+C、EOF、暂停，保留持久 shell。Linux 使用本机 Shell，支持中文、交互程序、尺寸调整和增量输出。
- **网页模型**：DeepSeek、Gemini、Qwen、Kimi、豆包、Claude 的扩展模式可通过 `nexus-tool-v1` 文本协议调用本机工具，无需网站原生支持 MCP。工具参数会校验，请求关联当前会话；支持审批、只读过滤、停止和重复调用去重。ChatGPT 保留原生 MCP 回传。
- **回复**：优先在软件聊天栏沟通。支持 GFM 表格、任务列表、代码复制，以及 `nexus-ui` 卡片、表格、指标和柱状图。网页回复保留代码块和表格格式。组件为声明式 JSON，不执行回复中的 JS/HTML。
- **执行显示和动画**：连续工具调用默认合并折叠，可展开逐条查看命令、参数、结果和耗时。补齐操作组展开/收起、组件和状态动效，尊重系统减少动态效果设置。轨迹记录改为异步批量写入。
- **Linux 完全控制**：选择完全权限后自动调用系统 `pkexec` 认证。授权后电脑控制服务以 root 运行，界面和浏览器仍在桌面用户下运行；界面显示实际 root 状态。退出完全控制会停止高权限服务及其终端。取消认证会恢复原权限，不保存“已提权”状态。需要 polkit 和运行中的桌面认证代理；Windows 仍使用当前登录用户的系统权限。
- **发布**：Windows x64 安装包、Linux AppImage/DEB、Linux 独立服务和浏览器扩展均从本版本提交构建。附带 SHA256SUMS.txt。

更新浏览器扩展后，请在浏览器扩展管理页重新加载，并刷新 AI 网页。网页模型是否遵循工具协议取决于模型和网站；发送、登录和验证码仍遵守网站实际状态。Linux root 的真实系统认证需要在装有 polkit 的目标桌面确认。
