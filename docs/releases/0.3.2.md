# NexusMCP Studio 0.3.2

修复网页版和桌面版模型菜单的布局错误，继续使用补丁版本号。

- MCP 提供商头像保持圆形，名称使用独立文字区域，修复头像被拉成长椭圆的问题。
- 模型菜单随可见视口调整位置和高度，兼容窄屏、横屏和软键盘出现后的可用空间。
- 预览说明放入标题栏，过长时省略，避免覆盖 MCP 服务状态。网页版不再预留桌面窗口按钮的空位。
- 内置桌宠默认避开输入区；窄屏停靠标题栏并预留空间，打开菜单或对话框时隐藏。已安装的工作搭子也适用。
- 窄屏输入工具栏限制文字宽度，保持发送按钮可见。桌面内置浏览器在菜单弹出时让出显示区域。

新增实际页面的模型菜单回归检查：七个提供商图标比例、菜单边界、键盘导航及焦点恢复；桌面源码和安装包复用检查。网页覆盖深浅主题、320–1440 像素宽度和较矮视口，并检查预览说明、桌宠及输入区之间的遮挡。

提供 Windows 安装包、Linux AppImage/DEB、独立服务和浏览器扩展。桌面用户需要安装本补丁以更新界面；网页版刷新即可。浏览器扩展无需重新配对。
