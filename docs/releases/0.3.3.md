# NexusMCP Studio 0.3.3

保持独立桌面与网页软件，将原生插件、思考显示、提问续传、本地会话和右侧工作区整合到同一个主窗口。继续按补丁版本小步更新，安装包、服务与浏览器扩展统一使用主程序版本号。

- **原生插件融入主程序**：内置固定版本的官方 DeepSeek Harness 兼容运行时，移除单独工作台入口。原生插件在统一插件页安装、设置、启停和卸载；更新前保存草稿，任务运行时阻止插件重启。实际验证 `Sutera-Diffusus/dsh-whale-musume@2.5.0` 的桌宠、启动表现、原生设置与生命周期。
- **思考与执行状态**：API 模型按能力发送实际思考等级参数，公开思考内容独立展示、可折叠；MCP 网页模式跟随网页设置，浏览器扩展回传页面已有的思考内容。执行状态、计时与工具结果以实际事件为准。
- **AI 在软件里提问**：支持选项和自由输入，提交后继续 API 或网页任务；等待期间不自动选择答案。停止会取消等待，历史保留回答。
- **真实连接自检**：依次检查 MCP、浏览器通道、当前网页绑定和一次隐藏测试对话。只有 AI 读取随机校验码并通过 `client_reply` 实际回传后才显示连接完成。测试消息不进入软件聊天历史；网页服务商可能保留该消息。普通网页正文不再被当作工具任务的最终结果。
- **本地历史和项目记忆**：消息、工具、问题、草稿与队列持久化；同一 Git 项目的工作树共享记忆，不同项目隔离。支持查看、编辑、清空和导出记忆，以及保留原文的上下文压缩。旧浏览器数据迁移前备份，删除的会话不会被旧缓存恢复。
- **右侧工作区**：文件预览、代码行号、Markdown、图片、PDF、文件搜索与引用、网页预览、项目记忆及 Git 审阅。支持暂存、取消暂存、提交、手动推送、创建工作树、差异评论和基于文件版本校验的撤销。
- **聊天工作流**：任务计划、消息队列及排序/暂停/取消、搜索/归档、回复复制、分支和重试草稿。空文件创建也显示为新增；工作区外部命令产生的文件变化会独立通知。
- **效率与稳定性**：原生会话采用增量日志、最多 8 个活动会话缓存和生命周期事件，减少重复传输、整份历史追加及反复打开日志；流式索引保存节流。界面启动和原生运行时启动合并并发请求。修复原生日志恢复标记、MCP 提前结束时网页停止、分享门户原生 WebSocket、弹层遮挡和窄屏布局。

这是 NexusMCP Studio 自己的项目、可执行程序和数据目录。官方运行时作为依赖使用，没有修改上游仓库。兼容性以 [原生插件验证范围](../HARNESS-COMPATIBILITY.md) 为准，不承诺未测试版本或所有第三方插件。

Windows 提供 EXE，Linux 提供 AppImage/DEB，同时提供独立服务和浏览器扩展。源码仓库不包含依赖目录、安装包、账户和本机运行数据。截图中的模型输出来自明确标注的本地测试接口；文件操作、命令、插件和持久化使用真实运行时验证。
