# NexusMCP Studio 0.3.1

本版本合并 0.3.0 验证分支的功能，并按补丁号推进。统一使用主程序版本号 0.3.1。

- **更少调用**：`workspace_read` 一条读取项目源码快照，`workspace_batch` 一次提交多步文件任务，`command_run` 一次运行命令并取得退出码。支持分页、容量上限、依赖目录过滤、并发读取、短时目录缓存、批量修改、原子替换与 hash 冲突检测；跳过相同内容的重复写入。
- **更快启动与传输**：终端、桌面、文件视图按需加载，主 JS 从本次优化前约 944 KB 降到约 470 KB；MCP 工具 schema 缓存、紧凑 JSON、异步批量日志、事件唤醒式 PTY 输出。浏览器扩展根据任务状态调整轮询，并缩短已完成工具回合的确认等待。
- **无原生 MCP 的模型**：DeepSeek 等网页通过扩展的文本工具协议操作本机，支持审批、只读过滤、结果回合、去重与停止。回复优先回到软件聊天栏，自动携带选中工作区路径。
- **更规范的对话**：工具组默认折叠，可逐条展开。展示实际退出码、参数、输出、耗时和文件增删行，提供差异预览。默认提示词明确先读取、选择批处理、核实结果、报告限制，不把工具 JSON 和日志当作最终回复。
- **更多回复组件**：GFM 表格、任务列表、代码复制；卡片、指标、图表、提示、步骤、进度、折叠详情、标签页、文件卡片和差异。全权扩展可继续注册自定义组件。
- **项目与预览**：右键项目打开资源管理器、在项目目录打开终端、浏览文件、复制路径、新建会话；聊天可置顶、导出与复制。支持代码/文本、Markdown、图片和 PDF 预览，以及网页版项目文件夹选择。
- **全权 Studio 扩展**：可修改 UI、添加启动动画与桌宠、注册工具/组件、接入运行时中间件。随附可安装的可拖动工作搭子示例，支持启停清理。详见 [开发接口](../STUDIO-EXTENSIONS.md)。
- **自动安装**：支持一键自动下载兼容 Chromium、预装浏览器扩展并配对，之后可启动时自动恢复。推荐 Studio 插件可自动安装并在启动时补齐。
- **应用图标**：使用图像生成模型制作新图标，接入窗口、网页、应用侧栏与 Windows/Linux 包。
- **Linux 完全控制**：自动请求系统 pkexec 认证，成功后电脑控制服务以 root 运行；取消授权恢复普通服务。界面和浏览器保持桌面用户身份。更换权限会重启 MCP 和终端，需要重新连接地址。Windows 沿用当前系统用户权限。

提供 Windows x64 安装包、Linux AppImage/DEB、Linux 独立服务、浏览器扩展与 SHA256SUMS.txt。更新扩展后请重新加载扩展并刷新 AI 网页。

Linux 图形授权需要目标机的 polkit 认证代理。Wayland 桌面控制仍受系统能力限制；SO 注入依赖可用的 gdb 与内核调试权限，某些运行环境存在 XSAVE 不兼容。大项目快照按上下文容量分批，不会把未读取、被排除或截断的文件报告为已完整读取。
