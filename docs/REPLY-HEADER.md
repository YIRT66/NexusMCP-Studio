# 从 AI 网页发起回复

连接同一个 NexusMCP 服务后，用户可以直接在 ChatGPT 等已启用 MCP 的网页中发消息，无需从软件输入框发起。

1. AI 调用 `client_session` 确认软件的会话。
2. AI 调用 `client_reply_start({sessionId,turnId,userText})`：软件立即显示“回复中”、占位消息和实际计时。`turnId` 是本轮唯一标识，重复调用不重置计时。`userText` 可选，只填实际用户原话。
3. 后续 `client_reply` 使用返回的 `requestId/sessionId`；最后一次 `done:true` 固定回复耗时。可以先 `done:false` 分段返回。

回复计时从首次调用回复头工具开始，无法推算调用前的网页思考时间。网页/客户端刷新后从服务端还原开始时间。点击“停止接收回复”会停止软件接收该轮结果；外部网页的模型生成需在网页停止。连接诊断不调用此工具。API 模型继续使用自己的流式通道。

这是源码更新，已发布的 0.3.4 安装包不会自动包含新工具；需要重新构建后使用，并刷新 MCP 工具列表。
