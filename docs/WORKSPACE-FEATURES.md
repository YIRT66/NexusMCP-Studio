# 会话、调试与公网远控

## 模型与时间轴

输入框的模型按钮分为可折叠的「MCP 模型」和「API 模型」。MCP 模型使用已登录网页，优先通过 `client_reply` 回传；未调用工具时，扩展会确认本轮助手回复已稳定且网页不再生成，再同步最终正文。识别聊天框时检查 iframe，并支持在扩展弹窗重新绑定当前标签页。

API 模型在设置中填写 OpenAI 兼容地址、模型 ID 和密钥，支持 JSON/SSE 响应、流式文本、工具调用、停止及失败后保留已接收正文。密钥保存在本机数据目录 `api-models.json`，不返回浏览器或写入浏览器存储。文本附件单个 200 KB、合计 400 KB。修改工具遵守本地审批设置；只读任务不向模型提供修改工具。

时间轴参考 [DeepSeek Harness](https://github.com/deepseek-ai/DeepSeek-Harness) 的轮次、概览与详情交互。提供输入/助手/工具三条轨道、真实时间/压缩空闲/等宽步骤、缩放、拖选时间范围、右键平移、搜索、折叠、输入输出检查和跟随最新记录。压缩空闲保留并发关系；未记录的开始或结束时间显示未知，不推算耗时。桌面与网页复用同一套动画，响应系统减少动态效果偏好。

## DeepSeek Harness 原生插件

「插件 → DSH 原生」可按需安装官方 `@deepseek-ai/dsh@0.2.1-rc.5`，需要 Node.js 24.9+，新版桌面包附带 Node 24。引擎与 `DSH_HOME` 位于本软件数据目录，与用户已有 DSH 配置隔离，设置 `DSH_TELEMETRY_DISABLED=1`。

Cordis bundle、原生服务及 UI 扩展由官方运行时在独立工作台执行，桌面打开专用窗口，网页版打开新标签页。兼容范围以该固定版本为准；不将原生 UI 插件冒充 MCP 工具。标准 MCP 清单与 SKILL.md 可直接安装到当前工作空间。依赖的安装脚本默认禁用；需要额外原生构建的插件应按其文档在本机准备。公网控制页不提供原生工作台管理。

## 内存与进程动态库

- `process_memory`：进程身份、内存统计、地址区域分页和指定地址读取，单次最多 65536 字节。
- `process_inject`：Windows DLL 或 Linux SO，先查询目标 PID、可执行文件和 `startIdentity`，再将该身份与动态库绝对路径传入。检查架构并核实实际模块映射，重复注入返回 `already-loaded`。Windows 加载超时返回 `pending`，应查询状态而非立即重试。
- Windows 使用系统调试 API；Linux SO 加载需要 `gdb`。沿用当前系统用户权限，受保护进程、Linux ptrace/Yama/容器限制会明确失败，不修改这些限制。动态库的初始化代码会在目标内执行，目标应是用户授权调试的进程；无法承诺自动撤销已执行代码的副作用。

## 网页控制台与注入

`browser_console_read` 开始采集页面控制台和异常，保留最近 500 条，支持游标。`browser_console_control` 支持 JS 执行、清空、暂停、恢复和终止脚本；`browser_inject` 支持 JS/CSS、后续导航继续注入及移除。移除可删除 CSS 和停止后续注入，已执行 JS 需自行清理副作用。

`target=managed` 为 `hancode_browser_open` 管理的浏览器；`target=chat` 为当前绑定的 AI 网页。内置 Electron 浏览器直接使用 CDP；普通 Chrome/Edge 需在扩展弹窗点击「开启网页调试」，启用当前网页调试（扩展安装时声明 debugger 权限），仅附加当前绑定的网页。浏览器会显示调试提示，关闭提示条会断开。AI 浏览器面板也提供控制台。控制台的敏感命名对象属性预览会隐藏，但脚本本身仍以该页面权限运行。

## 公网远控

设置 → 公网远控 → 开启公网访问，会建立 Cloudflare HTTPS 临时隧道并显示随机分享链接。链接持有人拥有当前控制台的桌面、键鼠、终端、文件与模型操作能力，只应交给可信人员。打开链接后使用 HttpOnly / Secure / SameSite Cookie；HTTP 与 WebSocket 均检查身份和来源，公网页不能管理分享入口或 DSH 原生工作台。

关闭入口会断开远程连接、撤销链接、停止由该入口启动的 API 请求与待批操作、关闭其新建终端；再次开启会轮换凭证。已经完成的文件修改或进程代码不会回滚。公网控制沿用当前工作空间，不是隔离的访客沙箱。

软件退出时清理隧道。临时地址不固定；建立隧道需要访问 Cloudflare。可用 `CLOUDFLARED_PATH` 指定本机程序。浏览器远控功能测试使用本地隧道替身验证转发、鉴权和撤销，不会在 CI 中开放真实设备到公网。

网页版：`npm run build && npm run service:start`，访问控制台输出的本机地址；独立服务包也包含构建后的网页。手机支持侧边栏抽屉、触摸目标、安全区域和原生文件上传。GitHub Pages 的静态预览只展示界面，不提供设备控制。
